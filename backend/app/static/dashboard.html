Event log

Retraining is a batch job. It runs after a session ends, never on a request path.
Every model version passes a gate. A worse score, or an implausibly good one, is refused.
The 2026 transfer table is code. Car and tyre features never learn from pre-2026 data.
Race predictions are gated off green. Safety car, VSC and red flag mark them low-confidence.
